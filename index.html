功能说明
1
客户总览 KPI
7 张指标卡构成看板第一屏。新增类指标（今日 / 本周 / 本月）带同比涨跌；累计、注册、签约反映整体客户盘子，签约率 = 签约数 ÷ 累计客户数；待跟进为红色预警值，联动下方跟进台账。
2
趋势与分布分析
双折线图支持「每日 / 每周 / 每月」×「新增数 / 累计数」六种组合切换，末端数值与 KPI 卡保持一致。环形图区分机构（42%）与个人（58%）；条形图展示经纪业务、交易咨询、API、资产管理四条业务线的客户数分布。
交互清单
  • KPI 指标卡 → 点击定位到对应台账
  • 趋势图「每日 / 每周 / 每月」×「新增 / 累计」六种组合切换
  • 环形图查看机构与个人客户占比
  • 条形图查看四条业务线的客户数分布
  • 待跟进预警值与下方跟进台账联动
3
机构视图与筛选
一行 = 一家机构 · 32 个字段
机构视图共 32 个字段、33 列，末列为操作列（表格横向滚动时吸附在右侧，始终可见）。
  • 表头分 6 组：基本信息（7）· 合规与适当性（4）· 业务线与归属（6）· 联系人信息（5）· 账号与安全（3）· 审计信息（7），共 32 个字段，末列为操作
  • 筛选栏共 27 个条件：关键词（投资者全称 / 用户id / 开户证件号码 模糊匹配）、用户级别（U0 / UA1 / UA2）、用户状态（活跃 / 注销）、法人属性、企业模式、业务单位、客户经理、客户战略等级、适当性等级、开户证件号码、证件类型、是否专业投资者、是否经纪业务客户、是否交易咨询客户、交易咨询已支付费用、是否资管客户、权益规模、登录方式、是否修改初始服务密码、电子密码器、推荐人，以及电子密码器分配时间 / 服务密码发送时间 / 创建时间 / 更新时间 / 登录时间 / 网络地址等时间类条件
  • 法人属性为单选：一般法人 / 特殊法人 二者其一，用下拉框选择，不做多选
  • 次要条件收进「更多筛选」：默认折叠，展开后时间类条件按区间查询
  • 业务单位与客户经理按业务线展示：经纪 / 交易咨询 / 资管三条线各自的归属单位与负责人分别列出，同一客户的多业务线数据分行呈现并配业务线彩色标签
  • 登录方式仅三种：手机号/邮箱登录、用户名登录、微信登录
4
行操作、详情与批量导入
  • 行操作：修改（打开「修改客户」弹窗）· 档案（打开该客户的档案管理弹窗）· 注销（二次确认后置为注销状态）· 重置密码（二次确认，展示客户姓名 / 用户id / 手机号）
  • 点击机构名称：打开「机构全景及成员」弹窗，含 基本信息 / 业务线与归属 / 账号与安全 / 审计信息 / 机构成员 / 客户档案 共 6 个面板

  • 导出 Excel：按当前筛选结果导出

机构视图具备完整档案中心能力（档案列表、版本号、上传维护）；成员与个人视图不提供档案列表，仅有行内「档案」入口，且按 客户角色 判定可用性 —— 仅 客户角色 = 个人 可点击，其余取值（管理员 / 操作员 …）为灰色只读。

  • 导入落点：批量导入写入的是「成员与个人客户」列表，机构客户走单独的建档流程

原样嵌入已上线申请页 · 申请表 / 审核中

  • 两个视图：申请表 · 审核中
  • 申请表流程：先选「申请权限类型」（支持搜索、多选，实时显示「已选择 N 项权限」），再填客户信息与备注，附件材料清单随所选权限动态生成

  • 适当性校验：部分服务面向适当性等级 C5 及以上开放，客户等级不足时给出提示并说明可开通的基础权限
  • 客户信息字段：客户全称（支持模糊搜索）、客户证件号码、11 位联系手机号、接收管理员账号密码的邮箱、硬件密码设备邮寄地址

平台级版本库与同步机制
机构视图只能选此处已维护的版本
档案管理中心是平台级的档案版本库：所有档案类型的版本在这里统一维护，机构视图只能选择此处已维护的版本，不再自行新增版本。
  • 同步条实时反映：已维护 N 个版本 / M 个档案类型，随上方任何操作即时刷新
  • 机构视图的「档案版本号」为下拉选择，选项仅来自此处状态为「启用」的类型版本；某类型被停用后，机构视图对应下拉会提示该档案类型已停用
  • 新增版本一律在本中心完成，避免两侧版本口径不一致
  • 导出清单：导出当前档案类型与版本明细，便于对账

上传并维护新版本
  • 档案类型：下拉选项来自上方类型表
  • 版本号：默认填充该类型下一个自增版本号（如已有 V2.1 → 建议 V2.2），可手动修改；用户正在输入时不会被自动覆盖

  • 按档案类型筛选：与上方类型表联动，也可在此单独切换
