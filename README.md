# 机构一站式服务平台 · 用户中心（客户总览看板）

一个**零依赖**的可交互 HTML 产品原型：左侧是真实可点的产品界面，右侧是功能说明文档，两侧通过 SVG 贝塞尔曲线连线一一对应。

打开 `index.html` 即可使用，不需要安装任何环境、不需要联网。

## 特点

- **零依赖**：不引用任何 CDN / 外部框架。样式为手写 CSS，图标为页内内联 SVG 精灵。断网、内网、离线环境下都能 100% 正常渲染。
- **原型即文档**：左侧 78% 是界面，右侧 22% 是琥珀色说明区，4 条编号连线把「界面元素 ↔ 功能说明」绑在一起。
- **真实交互**：不是静态截图 —— Tab 可切换、表格行可选中、弹窗能真正打开关闭、图表能切换维度。
- **一次生成全设备可用**：PC 左右分栏，窗口宽度 ≤ 900px 自动转为上下布局，连线隐藏并在每个区块下方直接显示简短说明，右下角按钮可切换「仅界面 / 界面+说明」。

## 怎么用

1. 鼠标悬停左侧带编号的元素 → 对应连线加粗高亮，右侧说明同步高亮
2. 鼠标悬停右侧说明 → 左侧对应元素同步高亮；**点击说明会自动滚动定位**到该元素
3. 点击「机构客户 / 成员与个人客户」Tab 切换客户主表
4. 表格行的「修改 / 注销 / 重置密码」、跟进表单的「新增跟进 / 详情」都会弹出真实交互弹窗
5. 趋势图可切换「每日 / 每周 / 每月」×「新增数 / 累计数」共六种组合

## 数据说明

**页面中所有数据均为示例 / 模拟数据**，仅用于演示交互与布局，不代表任何真实客户或业务数据。

## 技术实现

- 单个 HTML 文件，HTML + CSS + 原生 JavaScript 全部内联
- 连线绘制：`position: fixed` 的 SVG 层，`DOMContentLoaded` / `resize` / 滚动时重算；
  元素滚出可视区时自动不绘制，避免长页面里连线横穿整屏
- 图表：手写内联 SVG（折线图、环形图、条形图），无图表库
- 兼容性：现代浏览器（Chrome / Edge / Safari / Firefox）

## 生成方式

由 `prototype-html` skill 生成：左界面 + 右文档 + 连线高亮的产品原型规范。
