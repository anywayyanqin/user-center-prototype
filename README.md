# 机构一站式服务平台 · 用户中心

一个**零依赖**的可交互 HTML 产品原型：左侧是真实可点的产品界面，右侧是功能说明文档，两侧通过 SVG 贝塞尔曲线连线一一对应。

打开 `index.html` 即可使用，不需要安装任何环境、不需要联网。

## 页面结构（侧边栏 3 个视图）

左侧菜单点击切换 3 个视图：

| 视图 | 标题 | 内容 |
|---|---|---|
| 客户总览看板（首页） | 客户总览看板 | KPI 7 项 + 趋势图 + 客户类型/业务线分布 + 29 家业务单位排行 + 最近新增机构客户 |
| 客户管理 | 客户管理 | 机构视图（29 字段，含筛选栏）与成员与个人视图共用筛选栏；底部动作：批量导入 / 导出 Excel |

## 特点

- **零依赖**：不引用任何 CDN / 外部框架。样式为手写 CSS，图标为页内内联 SVG 精灵。断网、内网、离线环境下都能 100% 正常渲染。
- **侧边栏联动**：点击菜单项切换 3 个视图，每个视图自带 page-head 与对应的右侧说明区，切换时连线层自动重绘。
- **原型即文档**：左侧 78% 是界面，右侧 22% 是琥珀色说明区，编号连线把「界面元素 ↔ 功能说明」绑在一起。
- **真实交互**：不是静态截图 —— Tab 可切换、表格行可选中、弹窗能真正打开关闭、图表能切换维度。
- **一次生成全设备可用**：PC 左右分栏，窗口宽度 ≤ 900px 自动转为上下布局，连线隐藏并在每个区块下方直接显示简短说明。

## 怎么用

1. **点击左侧侧边栏菜单项**切换视图（首页 / 客户管理 / 跟进管理）
2. 鼠标悬停左侧带编号的元素 → 对应连线加粗高亮，右侧说明同步高亮
3. 鼠标悬停右侧说明 → 左侧对应元素同步高亮；**点击说明会自动滚动定位**到该元素
4. 客户管理内可点 Tab「机构视图 / 成员与个人视图」切换主表；筛选栏的「更多筛选」可折叠展开；法人属性为单选下拉
5. 表格行的「修改 / 注销 / 重置密码」、跟进表单的「新增跟进 / 详情」都会弹出真实交互弹窗
6. 趋势图可切换「每日 / 每周 / 每月」×「新增数 / 累计数」共六种组合

## 技术实现

- 单个 HTML 文件，HTML + CSS + 原生 JavaScript 全部内联
- 多视图路由：单页内 `<div class="view" data-view="...">` 容器 + `hidden` 属性切换；
  侧边栏 `data-view` / `data-tab` 触发 `switchView(view, tab)`，同时联动主表 view、右侧说明 rp-section、菜单高亮与连线重绘
- 连线绘制：`position: fixed` 的 SVG 层，`DOMContentLoaded` / `resize` / 滚动时重算；
  元素滚出可视区时自动不绘制，避免长页面里连线横穿整屏
- 图表：手写内联 SVG（折线图、环形图、条形图），无图表库
- 兼容性：现代浏览器（Chrome / Edge / Safari / Firefox）
